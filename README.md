# 📦 Inventory Manager

A simple warehouse management dashboard built with React.

## 🚀 Features

- Dashboard with statistics
- Low stock products modal
- Quick actions (add product / category)
- Sidebar navigation
- Responsive layout

## 🛠 Tech Stack

- React
- React Router
- Zustand (in progress)
- CSS / SCSS
- Lucide Icons
